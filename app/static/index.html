Home Assistant

Install the Stowaway integration from HACS, then enter this dashboard's address () and a token from here. Every app gets switches, sensors and buttons.

API tokens

Home Assistant and scripts use a token instead of your password. A token can see and control apps (wake, sleep, keep awake, switch off, restart) but can't change settings or your account. It only works from your home network unless you allow the dashboard from outside.
