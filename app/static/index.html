Containers on this server

Restart containers on a schedule, and optionally update them to the newest version at the same time. This works for any container, including ones Stowaway doesn't put to sleep. If a container is busy at its scheduled time, Stowaway waits for it to calm down. If a new version won't start, the previous one is put back.

Busy detection and awake hours

An app counts as busy, and isn't put to sleep, while its CPU or network use is above these. Each app can override them in Edit.

If something isn't working, a diagnostic report helps find out why. It's only shown or downloaded here: nothing is sent anywhere unless you attach it to a problem report yourself. Passwords, tokens and API keys are always removed.

Dashboards & Home Assistant

Show whether apps are awake, and when they restart next, on your dashboard tiles. Or control them from Home Assistant. Status addresses never wake an app.

API tokens

Home Assistant and scripts use a token instead of your password. A token can see and control apps (wake, sleep, keep awake, switch off, restart) but can't change settings or your account. It only works from your home network unless you allow the dashboard from outside.
